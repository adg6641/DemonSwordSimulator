# 마검사 시뮬레이터

Python · pico2d로 만든 2D 횡스크롤 액션 RPG + 인터랙티브 픽션의 첫 플레이 버전입니다.
인트로 → 시작 화면 → 8개 지역 → 마왕전 → 선택에 따른 엔딩 → 세계선 기록까지 진행할 수 있습니다.

## 실행

VS Code에서 이 폴더를 열고 `main.py`를 실행합니다. Python 디버거가 설치된 VS Code에서는 F5로도 실행할 수 있습니다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

수정 중에는 `python main.py --skip-intro`로 인트로만 생략할 수 있습니다. 시작 화면의 **이어하기**는 마지막 저장 지점으로 연결됩니다. **N**으로 새 모험을 시작하면 완결한 세계선 기록은 남습니다.

## 조작

레벨이 오르면 안전한 동작 구간에서 성장 선택창이 자동으로 열립니다. 현재 목표가 보이면 화살표가 목표 위에 뜨고, 멀리 있으면 주인공 가까이서 그 방향을 가리킵니다. 열린 성문 앞에서 E를 누르면 캐릭터가 문 안으로 걸어 들어갑니다.

| 키 | 행동 |
| --- | --- |
| ← → | 걷기 · 계속 누르면 달리기 |
| ↑ / ↓ | 점프 / 웅크리기 · 낮은 통로 이동 |
| 발판 위에서 ↓ + ↑ | 발판 아래로 내려가기 |
| C 연속 입력 | 기본 3연속 베기 · 각 베기마다 앞으로 한 걸음(웅크린 공격 제외) |
| Shift | 지상·공중 대시 |
| 대시 완료 후 C | 해금한 대시 베기. 이동 중의 C는 무시하며 Shift를 유지해 연결 가능 |
| Z → C | 해금한 마검파. MP를 써서 집중한 뒤 일정 시간 기본 베기마다 발사 |
| X | 정면 방어. 들어 올리는 순간 맞춰 막으면 피해 0·MP 회복 |
| E / H / Q | 조사·대화·쉼터 / 회복 파편 / 루네아 달빛 지원 |
| L | 남겨 둔 성장 선택 다시 열기 |
| Tab | 모험 기록·세계선 비교·엔딩 기록 |
| Esc | 일시 정지·안전한 위치 저장·다시 시작·은퇴 |
| 1~8 | 이미 도착한 지역으로 이동 |
| 선택창 ↑ ↓ / Enter | 선택 / 확인. 마우스와 화면에 표시된 숫자도 사용 가능 |

대화에는 짧은 상황 설명과 선택지가 함께 표시됩니다. 루네아와 상인 사건은 전투 HUD 없이 별도 구역에서 진행됩니다. 평소에는 오른쪽 위의 목표와 캐릭터 근처의 화살표로 다음 위치를 찾을 수 있습니다. 선택 결과와 복원 준비는 Tab 기록책에서 확인합니다.

주인공은 처음 만든 외형·비율·포즈를 기준으로 기본·전환 동작 55종과 이야기 동작 6종을 고해상도로 다시 그렸습니다. 걷기·달리기·대시는 원본 12프레임, 나머지는 원본 8프레임의 흐름을 따릅니다. 전환 동작의 시작과 끝은 연결할 동작의 그림과 맞췄습니다. 검은 원래 디자인을 선명하게 다시 그린 한 장을 손에 붙여 회전·이동하며, 손잡이에서 끝까지 길이113.85를 유지합니다. 검기·타격 판정·마검파 발사는 새 검의 위치와 같은 자세 시계를 사용합니다. 모든 프레임은 같은 머리 크기와 발 기준으로 다시 정렬했으며, 주인공의 표시 크기는15%, 루네아는 약21% 키웠습니다. 현재 자세와 가까운 연결 프레임으로 들어가고 전환·회수 구간의 시간을 조금 늘렸습니다. 지상·공중 대시는 장애물이 없을 때 모두 0.32초 동안 166px를 이동합니다. 지상에서는 뒷발로 밀고 나오며, 이동 중 착지하면 걸음을 이어갑니다. C의 첫째·둘째·셋째 베기에서 각각 46·54·64만큼 전진하며 웅크린 공격은 제자리입니다.

지역마다 상층 계단·승강 발판·좌우 이동 발판·붕괴 발판·달 조각·높은 상자·상층 쉼터가 있습니다. 도약 문양 위에서 ↑로 점프하면 더 높이 뜁니다. 걷기만 할 때는 튀어 오르지 않습니다. 새 덩굴 통로는 ↓로 들어가며, 안에서 키를 놓아도 밖으로 나올 때까지 낮은 자세를 유지합니다. 양옆 징검발판으로 지붕 위를 넘어갈 수도 있습니다. 카메라는 작은 점프·방향 전환에 바로 반응하지 않고, 고도에 따라 시야를 천천히 넓힙니다. 대화·메뉴·지역 전환에는 짧은 화면 교차 전환을 적용했습니다.

Esc → 다시 시작 · 은퇴에서 이번 진행을 초기화하거나 은퇴 엔딩을 보고 시작 화면으로 갈 수 있습니다. 이미 완결한 세계선 기록은 그대로 남습니다.

F9는 수정용 연습 키를 켭니다. 연습 키가 켜지면 숫자 1~8로 모든 지역에 이동하고 F1~F7로 검기 표현을 바꿀 수 있습니다.

## 한 판의 흐름

- 첫 레벨업에서 물리·마법·균형 방향을 고릅니다. 능력치 2점과 기술 1점은 따로 배분합니다. 이후 다른 계열의 기술도 배울 수 있습니다.
- 20종의 적과 싸웁니다. 공격 전 문양을 보고 피하고, 돌진 뒤의 빈틈을 노립니다. 상자·목책·봉인 기둥은 공격으로 부술 수 있습니다. 높은 발판에는 보상이 있고, 통나무는 투사체를 막습니다.
- 숲의 거울 웅덩이만 밤을 비추고, 물속의 가짜 목소리가 소녀의 이름을 빼앗으려 합니다. 루네아의 부적 신호를 따라 초승달·별·원 매듭을 풀거나 마검으로 강제 구출할 수 있습니다. 오답은 다시 살펴볼 기회를 줍니다. 구출 전용 원화 4장의 느린 확대·이동·교차 전환과 구출 후 첫 대화가 이어집니다. 강제 구출 시 부적의 균열은 제단·회랑에서 복구할 수 있습니다.
- 상인·제단·전령의 선택은 신뢰·침식·보급·적 배치에 반영됩니다. 밤·달·귀환의 기록과 비밀·기억·계획의 약속은 마지막 선택에 사용합니다.
- 최종 엔딩은 동반 4개·단독 4개·히든 1개입니다. 완전 복원에 부족한 조건은 왕좌와 기록책에 표시하며 회랑으로 돌아가 보완할 수 있습니다.
- HP 0은 종료 엔딩이 아닙니다. 약 2초의 실패 연출 뒤 적·보상·성장·이야기를 **직전 저장 시점으로 함께 복원**합니다. 모닥불과 지역 진입 시 저장되며, 전투 중에는 쉼터 회복을 사용할 수 없습니다.

진행과 완결 기록은 `userdata/save.json`에 로컬 저장합니다. 이 폴더는 Git에서 제외했습니다. 엔딩 후에는 이전 캐릭터와 비교하고 새로운 세계선을 시작할 수 있습니다.

## 수정할 파일

| 파일 | 바꾸는 내용 |
| --- | --- |
| `campaign_data.py` | 지역 배치·적 구성·대사·강화 선택지 |
| `campaign.py` | 사건 결과·진행·실제 타격·저장 시점 |
| `combat.py` | 적 AI·공격 패턴·투사체·동료 추적과 지원 |
| `navigation.py` / `rescue_story.py` | 동료 발판 경로 / 거울 웅덩이 구출 연출과 분기 |
| `progress.py` | 성장 수치·배분·복원 조건·9종 엔딩·저장 규칙 |
| `game_view.py` | HUD·선택창·성장창·기록책·엔딩 화면 |
| `story.py` | 현재 목표·짧은 대사·선택 기록의 쉬운 표현 |
| `player.py` | 기존 주인공 조작과 상태 전환 |
| `game_assets.py` | 이미지 로드·공통 시트 재생·UI 틀 |
| `application.py` / `main.py` | 인트로·메뉴·전체 실행 |
| `world.py` / `transitions.py` | 부드러운 카메라 추적·확대/축소 / 화면 교차 전환 |
| `effects.py` / `sound.py` | 검날 효과·마검파 / 짧은 효과음 |

새 주인공 시트는 `assets/hero/HD`에 있습니다. 바로 보이는 완성 시트와, 실제 렌더링용 `body`·`hands` 및 고정 검 `sword.png`를 구분했습니다. 손·검의 부착점과 재생 시간은 `assets/hero/animations.json`에서 수정합니다. 검기와 마검파는 실제 알파 픽셀을 타격 범위로 사용하고, 검날도 별도로 검사합니다. 기본·대시 베기는 단계에 따라 이펙트와 타격 범위가 함께 커집니다. 마검파의 기본 높이는1단계42에서7단계108까지 커지며, 대시 검기는 앞으로24만큼 더 나옵니다. 검기·마검파·검의 재 오라는 `assets/effects/HD`에 있습니다. 7단계 색은 같은 원화에 단계별 색조와 크기를 적용합니다. 구출·지형 원화와 생성 프롬프트는 `assets/expansion`, 기존 강조 문구·발판·말풍선은 `assets/polish`에 있습니다. 추가 자산은 [모험 이미지 미리보기](assets/adventure/모험_에셋_미리보기.html)에서 확인합니다.

## 검증

```powershell
python -m unittest discover -s tests -v
```

12개 단위 검사 외에 별도 SDL 실행으로 8개 지역, 전투 입력과 판정, 20종 적 패턴, 아홉 결말, 모든 등록 자산의 로드·렌더링을 확인했습니다. 실제 방향키와 점프로 높이 720까지 등반하고 동료가 뒤따르는 것, 이동·승강·붕괴 발판, 구출의 오답·강제·정상 분기도 검사했습니다. 첫 마을부터 D1·S3·H1 엔딩까지 실제 조작 진행을 확인했습니다. 피해량·적 간격·진행 시간은 코드에서 조정할 수 있습니다.
