# 마검사 시뮬레이터

**2D게임프로그래밍 1차 프로젝트 발표 및 게임 기획**

- 작성자: 게임공학과 이경서
- 학번: 2023180026
- 장르: 2D 횡스크롤 액션 RPG + 인터랙티브 픽션
- 개발 환경: Python, pico2d, Visual Studio Code
- 저장소: <https://github.com/adg6641/DemonSwordSimulator>

마왕의 마검을 우연히 주운 소년이 선택과 수련으로 성장하고, 마검을 되찾으러 오는 마왕에 맞서는 게임입니다. 직접 조작하는 액션과 이야기의 선택을 연결해, 매판 다른 성장 방향과 결말을 경험하도록 기획했습니다.

발표 PPT는 요약 발표용 자료입니다. 이후 구체화한 성장 선택과 사건·엔딩의 세부 규칙은 기획서 PPT와 Markdown 문서를 기준으로 합니다.

## 핵심 플레이

1. 기본 검 공격과 이동으로 첫 전투를 진행합니다.
2. 첫 레벨업에서 **대시 공격 특화, 마법 특화, 균형 성장** 중 하나를 고릅니다.
3. 이후 레벨업에서 선택한 방향의 스탯 또는 스킬을 강화합니다.
4. 모험 중 사건의 이득과 위험을 비교하고 선택합니다.
5. 누적된 선택과 보스전 결과에 따라 서로 다른 엔딩에 도달합니다.
6. 성장 방향과 선택 이력, 능력치와 엔딩을 저장해 이전 판과 비교합니다.

## 조작 계획

| 입력 | 행동 |
| --- | --- |
| 방향키 좌우 | 이동 |
| Space | 점프 |
| Ctrl | 웅크리기 |
| Shift | 대시 이동 |
| C | 기본 3연속 베기 |
| X | 방어 |
| 대시 중 C | 대시 베기, 기술 해금 후 사용 |
| Z | 마검파, 기술 해금 및 MP 조건 충족 시 사용 |
| 선택창에서 방향키 / Enter | 항목 선택 / 확정 |

## 개발 범위

완성할 한 판의 기본 범위는 성장 방향 3가지, 주 사건 3개, 일반 적 2종, 마왕 1종입니다. 기본 공격, 대시 베기와 마검파, 여러 엔딩, 로컬 기록 저장과 비교를 연결합니다. 온라인 순위와 추가 콘텐츠는 기본 범위에 포함하지 않습니다.

현재 저장소는 **기획 및 발표 자료를 관리하는 단계**입니다. 실행 가능한 게임 코드는 이후 개발 과정에서 추가합니다. 문서의 화면은 기획 예시이며, 피해량과 배율은 플레이 테스트 후 조정할 초기 설계입니다.
