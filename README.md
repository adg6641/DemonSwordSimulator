# 마검사 시뮬레이터

**2D게임프로그래밍 1차 프로젝트 발표 및 게임 기획**

- 작성자: 게임공학과 이경서
- 학번: 2023180026
- 장르: 2D 횡스크롤 액션 RPG + 인터랙티브 픽션
- 개발 환경: Python, pico2d, Visual Studio Code
- 저장소: <https://github.com/adg6641/DemonSwordSimulator>

마왕의 마검을 우연히 주운 소년이 선택과 수련으로 성장하고, 마검을 되찾으러 오는 마왕에 맞서는 게임입니다. 직접 조작하는 액션과 이야기의 선택을 연결해, 매판 다른 성장 방향과 결말을 경험하도록 기획했습니다.

## 핵심 플레이

1. 기본 검 공격과 이동으로 첫 전투를 진행합니다.
2. 첫 레벨업에서 **대시 공격 특화, 마법 특화, 균형 성장** 중 하나를 고릅니다.
3. 이후 레벨업에서 선택한 방향의 스탯 또는 스킬을 강화합니다.
4. 모험 중 사건의 이득과 위험을 비교하고 선택합니다.
5. 누적된 선택과 보스전 결과에 따라 서로 다른 엔딩에 도달합니다.
6. 성장 방향과 선택 이력, 능력치와 엔딩을 저장해 이전 판과 비교합니다.

## 개발 범위

완성할 한 판의 기본 범위는 성장 방향 3가지, 주 사건 3개, 일반 적 2종, 마왕 1종입니다. 기본 공격, 대시 베기와 마검파, 여러 엔딩, 로컬 기록 저장과 비교를 연결합니다. 온라인 순위와 추가 콘텐츠는 기본 범위에 포함하지 않습니다.

현재 구현은 **인트로 영상, 시작 화면, 8개 맵과 주인공 조작, 7단계 공격 이펙트를 연결한 pico2d 게임**입니다. 적 전투·충돌 판정, 실제 레벨업과 이야기 선택은 이후 단계입니다. 피격·쓰러짐 재생과 HP 처리는 `Player.take_damage()`에 연결했습니다. 문서의 성장 수치와 피해량은 초기 설계입니다.

## 실행과 현재 조작

Python 3에서 `python -m pip install -r requirements.txt`로 의존성을 설치한 후 `python main.py`로 시작합니다.

실행 즉시 나레이션·대사 자막 없는 35초·60FPS 인트로가 재생됩니다. 처음 3초는 검은 화면 뒤에서도 영상이 진행되며, 화면이 밝아지면 이미 걷고 있는 주인공이 보입니다. 검을 뽑은 뒤 검은 연기가 피어오르면 중간 확인 동작 없이 고퀄리티 손바닥 확인 컷으로 바로 전환됩니다. Enter/Space/Esc로 건너뛸 수 있습니다. 영상이 끝나면 검날과 검이 박힌 지점에서 반투명한 검은 연기가 천천히 피어오르는 시작 화면이 나타납니다. 게임 시작·조작 설명·종료를 마우스 또는 ↑/↓와 Enter로 선택합니다. 조작 설명은 펼쳐진 책으로 표시하며, Esc로 돌아갑니다.

- 방향키를 짧게 누르면 걷고, 계속 누르면 달립니다. 아래 방향키를 함께 누르면 웅크려 이동합니다.
- 위 방향키는 점프, Shift는 지상·공중 대시입니다. 공중 대시는 착지 전 한 번 사용할 수 있습니다.
- C를 이어 눌러 3연속 베기를 합니다. 방향키를 함께 누르면 조금씩 전진하며, 웅크린 공격은 제자리에서 합니다. 점프·웅크리기 중 C는 해당 자세의 공격입니다.
- Shift로 대시한 뒤 C를 새로 누르면 대시 베기를 합니다. 실제 대시 이동 중에 누른 C는 무시하며 자동 발동을 예약하지 않습니다.
- Shift를 유지하면 회복 모션이 끝나도 대시 공격 연결을 유지합니다. Shift를 놓아도 0.4초의 입력 여유가 있으며, 공중 대시와 착지 후에도 같은 규칙을 적용합니다.
- Z로 짧은 마력 집중을 마치면 5초 동안 강화됩니다. 강화 중 C의 기본 베기마다 마검파가 검끝에서 발사됩니다. 마검파는 캐릭터와 독립적으로 이동하며, 이펙트 미리보기에서 조정한 2배 속도를 사용합니다. X는 방어, Esc는 시작 화면으로 돌아가기입니다.
- F1~F7로 빨강·주황·노랑·초록·파랑·남색·보라의 7단계 검기를 선택합니다. 현재는 표현 확인용이며, 이후 실제 성장 선택과 연결합니다. 기본·대시 검기와 마검파는 1.5배 크기/75% 불투명도, 대시 검기는 진행 방향으로 10픽셀 앞을 기준으로 합니다. 검 전체에는 반투명한 검은 재 오라가 12프레임으로 반복됩니다.
- 현재는 동작 확인 단계이므로 대시 베기와 마법 모션을 모두 사용할 수 있습니다. 성장과 해금 처리는 아직 적용하지 않았습니다.
- 숫자 1~8로 해당 맵을 바로 선택합니다. 구간 오른쪽 끝은 다음 맵, 왼쪽 끝은 이전 맵으로 연결됩니다. 맵을 선택하면 주인공과 카메라를 출발 위치로 맞춥니다.

코드는 `main.py`(실행), `application.py`(인트로·메뉴·게임 전환), `interface.py`(시작 화면·책·HUD), `video.py`(MP4 스트리밍 재생), `player.py`(입력·주인공 상태), `effects.py`(검 오라·검기·마검파), `animation.py`(시트 재생), `world.py`(맵·카메라)로 나눴습니다. 원경은 지면보다 천천히 움직이고, 카메라는 좌우 이동과 높은 점프를 부드럽게 따라갑니다. 지면 8장은 새로 제작한 1280×256 PNG를 확대 없이 1:1로 표시하며, 좌우 반전을 번갈아 이어 붙입니다. 모든 이미지는 최근접 필터를 사용하고 배경과 캐릭터도 픽셀 좌표에 맞춰 그립니다. 큰 동작 프레임은 `animations.json`의 `renderScale`로 발 기준점을 유지한 채 비례 축소합니다.

시안 폴더와 HTML 예시를 정리하고 실제 사용하는 이미지는 `assets` 아래로 옮겼습니다. 55개 주인공 동작, 43개 공격·오라 시트, 배경과 지면 8종, 적 원화 20종을 보관합니다. 이번 인트로 수정은 걷기 시작·걷기·멈추기 시트와 시작 화면 오라, 총 4개 이미지를 교체했습니다. 걷기는 원래 인게임의 보행을 참고해 팔과 다리가 반대로 교차하도록 만들었습니다. 지지하는 발이 뒤로 이동한 거리에 맞춰 포즈 시간을 조정하고, 몸은 초당 140픽셀로 전진합니다. 검을 잡은 뒤에는 원화의 발바닥 중심을 프레임마다 정렬하여 주인공을 같은 월드 위치에 고정합니다. 배경·주인공·검을 모두 그린 후 전체 장면에 카메라 움직임을 적용합니다. 시작 화면은 같은 740픽셀 마검 클로즈업과 새 48프레임·8초 오라를 사용합니다. 연기는 검 가까이에서 선명하고, 멀어질수록 투명해지며 천천히 흩어집니다. 720p·60FPS 영상은 2,400프레임이며, 생성 프롬프트·원본 해시·배치 정보는 `assets/cinematic/cinematic.json`에 저장했습니다.
