# 배경과 지면 이미지

8개 맵의 지면을 새로 생성한 1280×256 PNG로 교체했습니다. 뒷배경은 기존 가로 파노라마이며, 지면은 1280×720 게임 화면에서 확대 없이 1:1로 표시합니다.

지면은 생성 원본에서 픽셀을 확대·축소하지 않고 잘랐습니다. 위에서 24픽셀 위치가 발을 맞추는 기준입니다. 지면을 늘리지 않고 원래 방향과 좌우 반전 방향을 번갈아 이어 그리므로 경계 픽셀이 맞닿습니다. 게임 속 충돌 바닥은 y=0입니다.

00_전체_미리보기.png는 새 지면을 배경에 겹쳐 본 자산 미리보기입니다. 실제 게임 창을 실행해 찍은 화면은 아닙니다.

키는 위 방향키 점프, 아래 방향키 웅크리기, 숫자 1~8 맵 선택입니다. 맵을 선택하면 주인공과 카메라가 출발 위치로 돌아갑니다.

내장 이미지 생성 도구로 새 지면 8장을 제작했습니다. 생성 프롬프트, 원본 크기, 자르기 좌표, 최종 크기는 asset_manifest.json의 ground 항목에 기록했습니다.
