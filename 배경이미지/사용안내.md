# 배경과 지면 이미지

8개 환경 구간의 뒷배경 8장과 투명 지면 8장입니다. 각 폴더의 뒷배경.png를 먼저 그리고 지면.png를 그 위에 배치합니다. 캐릭터, 적, HUD는 포함하지 않았습니다.

00_전체_미리보기.png는 두 이미지를 겹쳐 본 예시입니다. 원본은 가로 약 2170픽셀, 세로 약 724픽셀이며 파일별 정확한 크기는 asset_manifest.json에 기록했습니다. 미리보기용 크기 조절 외에 원본 이미지의 모양이나 색은 변경하지 않았습니다.

지면 PNG 위쪽의 빈 부분은 실제 투명 영역입니다. 그림과 충돌 판정은 별도로 관리하고 캐릭터의 발이 윗면에 닿도록 위치를 맞춥니다. 미리보기는 2160×720 화면에서 걷는 면을 대략 y=560에 두었습니다. 좌표는 왼쪽 위 기준이며 pico2d의 좌표계에 맞게 배치할 때 변환합니다. 각 이미지는 한 구간을 표현하는 가로 파노라마입니다. 좌우 끝이 정확하게 연결되는 무한 반복 타일로 검증한 자료는 아닙니다.

환경 흐름은 마을 출발, 숲 초입, 깊은 숲과 상인, 폐허 진입, 고대 제단, 마왕성 성문, 회랑, 최종 보스 왕좌 순입니다. 기존 모험의 진행을 시각적으로 나누는 자산 구분입니다.

내장 이미지 생성 도구로 제작했습니다. 모든 원본의 생성 프롬프트와 해상도는 asset_manifest.json에 함께 보관했습니다.
